# recycle: Smart Function Result Caching with Custom Argument Comparison

Provides intelligent caching of function results by comparing function
arguments using customizable comparison logic. Supports comparing
functions by code (ignoring environments), reading file contents instead
of comparing paths, and other flexible argument transformations before
determining if a re-run is necessary.
