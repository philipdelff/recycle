# Package index

## Main function

Core caching functionality

- [`recycle()`](https://philipdelff.github.io/recycle/reference/recycle.md)
  : Smart caching of function results with custom argument comparison

## Internal functions

Helper functions (not typically called directly)

- [`check_need_run()`](https://philipdelff.github.io/recycle/reference/check_need_run.md)
  : Check if function needs to be re-run based on argument changes
- [`digest_elements()`](https://philipdelff.github.io/recycle/reference/digest_elements.md)
  : Derive digests of argument values or their contents
- [`process_args_unwrap()`](https://philipdelff.github.io/recycle/reference/process_args_unwrap.md)
  : Process args.unwrap specification into unwrap functions
